# Bark Notify for Codex

任务结束后，按用户规则将请求和所选的结果回复发送到自己的 Bark。标题自动使用设备名称，副标题使用工作区名称。通知规则由使用者决定，配置只保存在本机。

## 一行安装

在终端执行（Windows、macOS、Linux）：

```sh
npx --yes github:BatuQI/bark-notify
```

需要 Node.js 18+（含 npm/npx）、Git、Python 3.9+。安装器会检查这些依赖，缺少时说明需要安装什么。直接从本公开 GitHub 仓库运行，无需 GitHub 登录或 token，也无需全局安装 npm 包。

首次安装时依次提示：

| 用户设置 | 推荐值 / 选择 |
| --- | --- |
| Bark 服务与 device key | 官方服务或自建 HTTPS 服务；填写自己的 key |
| 消息分组 | example，可修改 |
| 保留时间 | 一天（86400 秒），可修改 |
| 正文格式 | 普通正文，可选 Markdown |
| 是否包含任务回复 | 是，可改为仅用户请求 |
| 是否清理本地链接和显示标记 | 是，可关闭 |
| 回复过长时是否显示简短结果状态 | 默认关闭，用户选择后开启；成功显示“已完成” |
| 何时通知 | 仅明确调用、每个任务结束（成功、失败、取消或被拦截），或自己描述条件 |

只有选择所有任务或自定义条件，才写入相应的全局通知规则。首次向导默认“仅明确调用”，不会未经选择就授权发送所有任务。标题和副标题自动读取；特殊环境可用 `BARK_DEVICE_NAME` 自定义设备名。

“每个任务结束”包含独立聊天和只读任务。同一次结束只调用一次通知脚本；等待输入、等待审批、仍在执行或修复中不发送，审批或执行被拒绝且任务就此结束则发送结果。取消或拦截后仍能执行工具时可发送；强制停止或进程退出使工具无法运行时，Skill 无法保证通知，也没有后台补发。已有用户的通知范围在更新时原样保留，明确要求改变规则后才修改。

安装目录是 `$CODEX_HOME/skills/bark-notify`，未设置 `CODEX_HOME` 时为 `~/.codex/skills/bark-notify`。旧 ZIP 安装会先备份到 `CODEX_HOME/bark-notify-backups`，再迁移本地配置。已有配置和规则原样保留，不重新提问。完成后新建聊天或重启 Codex 加载。

## 让 Codex 帮你安装

把仓库内的 [安装提示词](INSTALL_PROMPT.md) 发给 Codex。它会先了解你的首次配置选择，再实际安装；已有配置时直接沿用。安装提示词不强制任何全局默认规则，也不创建自动更新任务。

## 手动更新

需要更新时自行执行：

```sh
npx --yes github:BatuQI/bark-notify --update
```

也可以在已安装的 Git 工作副本中执行 `git pull --ff-only`。更新只替换仓库代码和说明；`config.json` 和本机全局通知规则不受影响，不再次弹出首次配置向导。不要为普通更新重新运行 `--enable-default`。本工具不安装定时任务或后台自动更新。

有代码改动、分支不符或分叉时停止更新，交给使用者处理，不重置或隐藏本地改动。只读下载和更新无需登录；维护者提交、推送代码仍需要仓库写入权限。

## 长回复降级

可选设置 `long_reply_fallback=true`：待发送 JSON 超过 3500 个 UTF-8 字节时，保留用户请求，只将回复替换为结果状态。成功显示“已完成”，失败、取消或拦截显示对应状态；完整输入与聊天回复不变。3500 字节是预检预算，不是所有服务的固定上限。

若完整版本明确收到 HTTP 413，脚本最多用短版本再试一次；已缩短仍失败、网络超时和其他错误不重试。用户请求本身过长时仍可能失败，不会截断请求。首次安装需主动选择，旧配置缺少该字段时保持原行为。详细输入格式见 [安装与配置](references/setup.md)。

## 本地设置

以后想调整消息内容、保留时间或接收端，可以明确要求 Codex 修改本机 `config.json`；想调整何时通知，则修改自己的全局 Bark 规则。更新不会把已有用户的十分钟设置改为一天，一天只是首次安装的推荐值。

仓库和通用安装包只包含 `config.example.json`，不包含真实 key。`.gitignore` 排除本地配置、环境文件和个人 ZIP。不要把真实 key、全局 AGENTS.md 或聊天记录提交到仓库。

详细参数、无 Node 安装及停用方法见 [安装与配置](references/setup.md)。
